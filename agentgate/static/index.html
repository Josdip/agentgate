How to plug in an agent
  1. Implement your model or framework adapter in examples/real_agent_demo.py.
  2. Return proposed tool calls through agentgate.client.GatewayClient. AgentGate evaluates and executes them.
  3. Run the adapter locally and watch its actions appear in the activity feed. Refunds requiring approval pause for your decision.

This slot does not launch code from the browser. Its label describes scaffold readiness, not live connection monitoring. Model inventory entries are maintained separately.
